A model code, resolved against the catalogue and the code-shape rules. Everything runs in this page; the data is static JSON.

{}

The JSON is the API

This page is a reader for it. No server is involved, and the same files answer a fetch or a curl:

  • api/SM.json — every catalogued code starting SM, as {"SM-S928B": ["Samsung", "Galaxy S24 Ultra"]}
  • api/rules.json — the code-shape rules, for codes the catalogue does not hold
  • api/meta.json — snapshot date, device count, source
  • api/devicex.js — the client used here, importable as an ES module

A shard is named after the first two characters of a code, uppercased, with anything that is not a letter or a digit replaced by _. A missing shard means no catalogued code starts with them.

A plain path answers too: /d/SM-S928B.
